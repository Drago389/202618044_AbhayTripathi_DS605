# Airbnb Price Predictor

A machine learning project to predict Airbnb nightly prices in New York City.

## Overview
This project builds an end-to-end ML workflow for Airbnb price prediction, including data preprocessing, model training, evaluation, and a Streamlit web application.

## Installation
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`

## Usage
1. Run the Jupyter notebook to train the model.
2. Run the Streamlit app: `streamlit run app.py`
